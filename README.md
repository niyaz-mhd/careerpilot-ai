
# CareerPilot AI

An AI-powered career development platform that helps
users build professional resumes, improve their resumes
with AI feedback, and prepare for job interviews.

## Features

- User authentication
- Personal dashboard
- Professional resume builder
- AI-powered resume review
- AI mock interview practice
- Interview history and analytics

## Tech Stack

### Frontend
- React
- TypeScript
- Vite
- Tailwind CSS

### Backend
- Node.js
- Express.js
- TypeScript
- Prisma ORM
- PostgreSQL

### AI Integration
- OpenAI API / Gemini API

## Project Structure

- client/ - Frontend application
- server/ - Backend application
- docs/ - Project documentation

Currently in development.
